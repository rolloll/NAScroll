NAScroll 1.2.0 - 설치 및 사용 안내
===================================

NAScroll은 Synology NAS의 DSM File Station에 직접 연결하여 이미지 폴더, EPUB, TXT,
PDF 파일을 읽는 Android 앱입니다.

지원 Android 버전: Android 7.0(API 24) 이상
앱 버전: 1.2.0 (versionCode 3)


[1단계] APK 준비
------------------------------------------
배포받은 APK를 사용하거나, 소스 코드에서 직접 빌드할 수 있습니다.

- 디버그 빌드:
  .\gradlew.bat :app:assembleDebug
  결과 파일: app\build\outputs\apk\debug\NAScroll-debug.apk

- 릴리스 빌드:
  .\gradlew.bat :app:assembleRelease
  결과 파일: app\build\outputs\apk\release\NAScroll.apk

현재 소스 코드에는 릴리스 서명 키가 포함되어 있지 않습니다. 릴리스 APK를 배포하려면
별도로 서명해야 합니다. 서명되지 않은 릴리스 APK는 설치하거나 배포할 수 없습니다.


[2단계] 휴대폰에 APK 설치
------------------------------------------
1. APK 파일을 USB, 클라우드 저장소, 메신저 파일 전송 등으로 휴대폰에 옮깁니다.
2. 휴대폰의 파일 관리자에서 APK 파일을 엽니다.
3. 안내가 표시되면 APK를 연 앱에 대해 "알 수 없는 앱 설치"를 허용합니다.
4. 설치를 완료한 뒤 NAScroll을 실행합니다.

Android 8 이상에서는 처음 설치할 때 파일 관리자, 브라우저, 메신저 등 APK를 연 앱별로
설치 권한을 허용해야 할 수 있습니다.


[3단계] NAS 로그인
------------------------------------------
1. NAS 주소에 평소 DSM에 접속하는 주소를 입력합니다.
   예: https://nas.example.com:5001
2. DSM 계정과 비밀번호를 입력합니다.
3. "로그인"을 누릅니다.

NAS 주소는 반드시 http:// 또는 https://로 시작해야 합니다. 외부 네트워크에서 접속할
때에는 HTTPS 사용을 권장합니다.

앱은 실행할 때 하루에 한 번 GitHub의 최신 버전을 확인합니다. 새 버전이 있으면 업데이트
알림의 "다운로드"를 눌러 GitHub APK 다운로드 페이지를 열 수 있습니다. 네트워크가 없거나
GitHub에 연결할 수 없는 경우에는 기존 기능을 계속 사용할 수 있습니다.

로그인하면 NAS의 최상위 공유 폴더 목록이 표시됩니다. 원하는 공유 폴더와 하위 폴더를
차례로 열어 파일을 찾습니다.


[사용 방법]
------------------------------------------
- 폴더를 눌러 하위 폴더로 이동합니다.
- 상단의 경로 표시를 눌러 상위 폴더로 이동할 수 있습니다.
- 이미지가 있는 폴더에서는 "전체 보기" 또는 썸네일을 눌러 이미지 리더를 엽니다.
- EPUB, TXT, PDF 파일을 누르면 각 파일 형식에 맞는 리더가 열립니다.
- 브라우저 상단의 독서노트 메뉴에서 책갈피와 하이라이트를 한 곳에서 확인합니다.

리더 화면에서는 화면을 한 번 눌러 상단/하단 바를 숨기거나 다시 표시할 수 있습니다.
리더 설정에서 테마, 글꼴, 글자 크기, 여백, 줄 간격, 문단 정렬, 밝기와 탭 영역을
조절할 수 있습니다.

EPUB 리더는 목차, 챕터 이동, 책갈피, 하이라이트와 읽던 위치 복원을 지원합니다.
TXT 리더는 스크롤/페이지 읽기 방식을 지원하며, PDF 리더는 페이지 보기와 연속 스크롤을
지원합니다.


[업데이트]
------------------------------------------
기존 앱 위에 새 APK를 설치하려면 다음 조건이 모두 맞아야 합니다.

- 앱 패키지 이름이 같아야 합니다.
- 새 APK의 versionCode가 더 높아야 합니다.
- 기존 APK와 새 APK가 같은 서명 키로 서명되어야 합니다.

조건이 맞으면 앱 데이터(로그인 정보, 책갈피, 하이라이트, 읽던 위치)를 유지한 채
업데이트할 수 있습니다. 서명 키가 다르면 Android가 덮어쓰기를 거부합니다. 이 경우
기존 앱을 삭제하면 새 APK를 설치할 수 있지만, 앱에 저장된 로컬 데이터도 함께 삭제됩니다.

새 버전을 GitHub에 올릴 때에는 app/build.gradle.kts의 versionCode/versionName을 올리고,
APK를 저장소에 업로드한 뒤 기본 브랜치의 update.json도 같은 버전으로 수정해야 합니다.
update.json의 apkUrl은 휴대폰에서 열 수 있는 GitHub APK 주소여야 합니다.


[보안 및 개인정보]
------------------------------------------
- 자동 로그인을 위해 NAS 주소, 계정, 비밀번호가 기기의 앱 전용 SharedPreferences에
  저장됩니다. 기기를 다른 사람과 공유하거나 루팅된 기기를 사용하는 경우에는 주의하세요.
- NAS 관리자 계정 대신 필요한 폴더에 대한 읽기 권한만 가진 별도 DSM 계정을 권장합니다.
- 가능한 한 HTTPS와 신뢰할 수 있는 인증서를 사용하세요.
- 책갈피, 하이라이트, 읽던 위치는 기기 내부 SQLite 데이터베이스에만 저장되며 NAS
  원본 파일에는 기록되지 않습니다.
- 읽기 위해 내려받은 EPUB, TXT, PDF 파일은 앱 캐시에 남을 수 있습니다. 민감한 파일을
  읽었다면 Android 설정에서 앱 캐시를 비우는 방법을 고려하세요.
- 2단계 인증(OTP) 흐름과 DRM으로 보호된 전자책은 지원하지 않습니다.


[문제 해결]
------------------------------------------
- 로그인이 안 될 때
  NAS 주소가 http:// 또는 https://로 시작하는지, 포트 번호가 정확한지, 계정에 File
  Station 접근 권한이 있는지 확인하세요.

- 외부에서만 접속이 안 될 때
  NAS의 HTTPS 인증서, 방화벽, VPN 또는 네트워크 접근 설정을 확인하세요. NAS를 인터넷에
  직접 노출하는 경우에는 DSM의 보안 설정을 먼저 점검해야 합니다.

- 폴더나 파일이 보이지 않을 때
  로그인한 계정에 해당 공유 폴더의 읽기 권한이 있는지 확인하고, 화면을 아래로 당겨
  새로고침하세요.

- EPUB 내용이 기대와 다르게 보일 때
  EPUB은 화면 크기, 글꼴, Android WebView 버전과 리더 설정에 따라 다시 배치됩니다.
  DRM, 고정 레이아웃, 복잡한 CSS 또는 손상된 EPUB 파일은 일부 기능이 제한될 수 있습니다.

- 앱을 다시 로그인 상태로 만들고 싶을 때
  앱 설정에서 로그아웃한 뒤 NAS 주소와 계정을 다시 입력하세요.
